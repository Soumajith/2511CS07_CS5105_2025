Student Grouping App Instructions
Follow these simple steps to run the Student Grouping application on your computer.

Prerequisites
You only need Python installed. If you don't have it, you can download it from the official website:

Step 1: Unzip the Project Folder
First, unzip the file you downloaded to create a new folder on your computer. You can place this folder anywhere you like (e.g., your Desktop).

Step 2: Open a Terminal
You need to open a command-line tool to run a few simple commands.

Step 3: Navigate to the Project Folder
In the terminal you just opened, use the cd command to go into the folder you unzipped in Step 1.

Example: If you unzipped the folder to your Desktop, you would type:

cd Desktop/student-grouping-app

(Replace student-grouping-app with the actual name of the folder).

Step 4: Install the Required Libraries
Now, run the following command. This will automatically install all the necessary libraries for the app to work.

pip install -r requirements.txt

Wait for the installation to complete.

Step 5: Run the Application
You're all set! Run the final command to start the application:

streamlit run app.py

A new tab should automatically open in your web browser with the Student Grouping application running. You can now upload your files and start creating groups.
